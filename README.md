# Cafe-Menu
A simple form project built using HTML and CSS that I learnt from Freecodecamp

## 📸 Preview
![Camper Cafe Preview](./preview.png)

## 🛠️ Built With

- HTML5
- CSS3

## ✨ Features

- Display cafe name and establishment year
- Display coffee menu and prices
- Display dessert menu and prices
- Simple and clean cafe menu design

## 🚀 How to Run

1. Clone this repository
2. Open the project folder
3. Open `index.html` in your browser

## 📚 Learning Source

This project was created while learning HTML and CSS through FreeCodeCamp.
